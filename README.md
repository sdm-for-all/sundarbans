# sundarbans
A Django webapp to interact with various species distribution models (SDMs) for a user-selected bird species. Currently limited to the Sundarbans. 

# How to use

Navigate to the root directory in terminal (example: `cd "D:\sdm-django"`) and run using `python manage.py runserver`

To add new species, create a new Jupyter notebook with one of the other notebooks as a template. The only one you can't use is pitta_nympha, because it is a [notebook taken from the Google Earth Engine tutorials](https://developers.google.com/earth-engine/tutorials/community/species-distribution-modeling) from Google for Developers. The region for it is South Korea and it has not been adapted for Scenario mode. It remains in the repo for posterity.
